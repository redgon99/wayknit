**여로담 관리자 모드 검토 — 2026-09-16**

검토 대상: https://wayknit.com 의 로그인된 관리자 화면과 현재 작업공간의 관련 코드.

전체 평가: 콘텐츠 수집·생성·발행, 랜딩 편집, 신고 처리, 감사의 기본 구성은 갖춰져 있다. 다음 개선의 중심은 운영본을 안전하게 수정하는 기능, 콘텐츠 품질 검수, 변경 대상과 작업자를 추적할 수 있는 감사 기록, 실제 회원을 기준으로 하는 사용자 관리다.

**검토 범위와 근거 구분**

- 화면 확인: 대시보드, 현황 관리, 시장 인사이트의 3개 탭, 가이드 목록·편집, 배포 검토 큐·편집·계정 관리, 시나리오 목록·한국어/영어 미리보기, 랜딩 관리·모바일 미리보기, 신고 전체 목록, 감사 상세·필터, 전역 검색.
- 동작 확인: ‘부산’ 전역 검색, 사용자 목록 다음 페이지, 대시보드 계정 연결 링크, 관리자 메뉴를 통한 랜딩 진입과 새로고침.
- 운영 데이터 저장·삭제·게시·복원, 외부 SNS 게시, AI 생성·수집은 실행하지 않았다. 코드 검토 사항은 운영 DB의 실제 함수 정의와 동일함을 보장하지 않는다.
- 화면에서 확인한 사실, 코드에서 확인한 구조, 추가 기능 제안을 구분했다. 보안 침투 테스트나 전체 여행 정보의 사실 검증은 이번 범위에 포함하지 않았다.
- 이메일·사용자 UUID·인증정보는 이 보고서에 싣지 않았다.

**메뉴 재구성 제안**

| 상위 메뉴 | 하위 메뉴 |
|---|---|
| 대시보드 | 처리할 일, 운영 상태, 주요 지표 |

| 배포 | 배포 초안, 승인·예약, 게시 이력, 채널·계정 |

상단 메뉴를 전부 같은 비중으로 나열하는 대신 업무 단위로 묶는다. ‘공지사항’과 ‘랜딩 공지띠’는 노출 위치를 명시하고 서로의 관리 화면으로 연결한다.

**권장 실행 순서**

1. 게시 안전성: L1·L2·A1·A2를 우선 처리. SNS 계정 연결 전 A3 확인·수정. L3 새로고침 문제도 함께 수정.
2. 실제 콘텐츠 운영: C1~C4로 검수·수정·버전 관리를 완성하고, D1~D3에서 우선 운영할 채널 하나의 게시 흐름을 완성. 현재 9개 미지원 채널 초안은 수동 배포 보조 흐름으로 관리.
3. 운영 정확성: U1·U2·M1로 회원·테스트·지표를 분리하고, A4·R1로 추적과 신고 처리 근거를 보강.
4. 사용성·확장성: 메뉴 재구성, 정확한 작업 바로가기, 목록 탐색, 상태 표시를 정리. 이후 예약·다국어 검수·성과 측정을 확장.

**검증 범위의 한계**

실제 발행 성공률, 계정 연결, 생성 품질의 전체 분포, 비관리자 권한 차단, 복원 성공 여부는 실행 검증하지 않았다. 보이는 버튼의 존재를 실행 성공으로 평가하지 않았으며, 운영 데이터에 영향을 줄 수 있는 문제는 코드 근거와 함께 후속 검증 대상으로 제시했다. 이번 작업은 분석 보고서 작성이며 서비스 코드·DB·게시물은 직접 변경하지 않았다.
