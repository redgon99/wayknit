# 모바일 화면 점검 — 2026-09-10

대상: http://localhost:5173. 실제 Google Chrome 별도 검사 프로필에서 390×844, 터치·모바일 에뮬레이션으로 확인했다. 홈·플래너·한국여행정보·공유마당은 360px 및 320px에서도 추가 확인했다. 해당 기본 화면에서 문서 가로 넘침은 관찰되지 않았다.

기존 Chrome의 개발자 도구 단축키는 macOS 키보드 자동 제어 권한에 막혀 실행하지 못했다. 대신 Chrome DevTools Protocol 기기 에뮬레이션을 사용했다. 검사 프로필은 비로그인·빈 일정 상태다. 관리자, 로그인 완료, 클라우드 저장, 유효 일정의 경로 계산·드래그, 실제 공유 발행·신고·삭제, 파일 선택/업로드, 실제 휴대폰 키보드·GPS는 검증하지 않았다. 따라서 모든 기능의 끝까지 검증 완료를 의미하지 않는다. 앱 소스는 수정하지 않았다.

## 개선사항

| 우선순위 | 화면 | 관찰한 현상 | 개선안 |
|---|---|---|---|
| 높음 | 공유마당 | 비로그인 화면에 작성자 이메일 원문이 표시된다. | 기본 작성자 표시는 닉네임으로 제한하고 이메일 공개 여부를 점검한다. |
| 높음 | 홈·모바일 메뉴 | 제목이 ‘본문’인 빈 섹션 두 곳과 임시 제목 ‘홍보이미지’가 표시된다. 본문 없는 구간이 긴 스크롤을 만든다. | 비어 있는 섹션은 숨기고 실제 내용을 설명하는 메뉴명으로 바꾼다. |
| 높음 | 공통 안내 | 홈은 ‘9월 테스트기간’, 공유마당·가이드는 ‘8월 시범, 9월 정식 운영’이다. | 운영 안내를 한 데이터에서 출력한다. |
| 중간 | 플래너·도움말 | 상단 검색/설정은 36×36px, 일차는 높이 32px, 하단 메뉴 항목은 35px, 도움말 복사는 26px다. | 주요 터치 영역을 44~48px로 확대하고 인접 버튼 간격을 확보한다. 지도 공급자 자체 UI는 별도다. |
| 중간 | 장소 검색 | 경복궁 검색에서 상점이 먼저 나오며 궁궐 경복궁은 아래쪽이다. 동명 결과도 여러 개다. | 기본 관련도 정렬, 정확한 이름 가중치, 주소·종류 표시와 중복 후보 구분을 보강한다. |
| 중간 | 플래너·가이드 | 한국어에서 reviews, DEPART, TRANSPORT, OPTIMIZE, STAY TIME, AI suggest, Build route 및 food/other 같은 태그가 보인다. | 사용자 문구와 분류 태그를 한국어로 통일한다. |
| 중간 | 여행 자료 | 모바일 메모 입력창에 ⌘/Ctrl+Enter 안내, 빈 자료 화면에 ‘파일을 끌어오기’ 안내가 보인다. | 모바일에는 ‘사진·파일 버튼으로 추가’, ‘저장 버튼을 누르세요’로 안내한다. |
| 중간 | 빈 일정 | 빈 화면의 직접 실행 버튼은 ‘읽어오기’이며, 검색하라는 문장은 버튼이 아니다. | 빈 일정 중앙에 ‘장소 검색’ CTA를 추가하고 가져오기는 보조 동작으로 둔다. |
| 중간 | 검색 입력·필터 | 긴 한영 검색 안내가 입력 폭에서 잘린다. 지도 제공자 선택은 28px 아이콘 중심이다. | placeholder를 짧게 하고 장소/링크 검색 도움말을 분리한다. 제공자 이름과 선택 상태를 명확히 표시한다. |
| 중간 | 공유마당 | ‘목업’ 작성자와 mock 경로를 가진 테스트 항목들이 실제 공유 글과 섞여 보인다. | 공개 목록에서 테스트 자료를 분리하거나 데모임을 명확히 표시한다. 개발 환경 전용인지도 확인한다. |
| 낮음 | 관광사진 | 촬영 시점에 2012.00, 2018.00 등 월 00이 표시된다. | 월이 없으면 연도만 표시하고 유효하지 않은 월은 출력하지 않는다. |
| 낮음 | 홈 예시 | ‘핀 목록 · 4곳’인데 눈에 보이는 예시는 3곳이다. | 표시 수를 예시와 맞추거나 ‘외 1곳’을 표기한다. |
| 낮음 | 모바일 자료 입력 | 메모 작성창이 화면 하단에 배치된다. 에뮬레이션에는 실제 소프트 키보드가 없다. | 실제 iOS/Android에서 키보드가 저장·취소 버튼을 가리는지 추가 검증한다. 현재 확인된 버그가 아닌 후속 검증 항목이다. |

## 실행 범위

- 홈: 화면·햄버거 메뉴 열기 확인. 기능/시작하기 앵커 각각의 도달 위치는 미검증.
- 플래너: 여행 설정, 일차 메뉴, 검색, 필터, 전국/지도 주변 전환, 경복궁 검색 결과, 목록/동선 화면, 가져오기 메뉴.
- 하단: 자료 열기·메모 입력창, 시나리오 열기·명상관광 선택 및 준비된 코스 목록, 메뉴 열기.
- 하단 메뉴: 공유 대화상자, 관심 테마, 표 보기, 한국 준비, 도움말, 계정.
- 공유마당: 게시판 표시, 필터 열기, 지도 전환. 공유 글 상세·끌어오기·신고 제출은 미검증.
- 여행 가이드: 추천 여행코스·유용한 정보·여행 준비·맛집/카페·문화/에티켓·쇼핑/면세·안전/응급 분류 선택. 본문 상세 전체는 미검증.
- 한국여행정보: 관광사진·걷기 코스·오디오 가이드·지역 방문자 통계·반려동물 동반여행·무장애 여행 탭 전환 및 내용 표시. 각 항목의 모든 상세·재생·외부 링크는 미검증.
- 독립 페이지: 한국 준비, 도움말, 테마 보드, 로그인, 이용약관, 개인정보처리방침 표시.
