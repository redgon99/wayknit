# 로그인한 iPhone 크기 화면 추가 점검

2026-09-10. 사용자가 로그인하고 기기 에뮬레이션을 설정한 기존 Chrome 탭에 연결했다. 뷰포트는 **390×844 CSS px**이며 사용자의 기기 설정을 유지했다. ‘춘천여행1일짜리’의 핀 5개가 있는 일정으로 점검했다. 특정 iPhone 모델명·실기기 Safari 결과를 뜻하지 않는다.

이번에는 비로그인 검사에서 제외했던 공유 화면, 협업자 관리의 사람/활동 탭, 계정, 요금제 안내를 열어 확인했다. 장소 검색, 목록/동선 보기, 표, 여행/일차 메뉴, 자료, 시나리오, 택시 카드도 확인했다. 메뉴 동작은 DOM 클릭으로 실행했고 화면 캡처 및 실제 요소 크기를 확인했다. 손가락 터치·드래그 제스처의 성공까지 검증한 것은 아니다.

## 추가 개선사항

| ID / 우선순위 | 관찰 및 재현 | 개선 방향 |
|---|---|---|
| M01 / 최우선 | **검색 결과가 있어도 카드가 0개처럼 보인다.** 반높이 패널에서 ‘춘천 숙소’ 검색 → 결과 15개, 더보기만 표시. `.search-result-list`는 **clientHeight=0, scrollHeight=1169**. 펼치면 **clientHeight=238**로 카드가 보인다. | 결과가 생기면 패널을 자동 확장하거나 목록 최소 높이를 보장한다. 헤더·검색·필터·더보기 높이를 줄여 첫 결과가 항상 보이게 한다. |
| M02 / 높음 | **일정 5개인데 기본 화면에서 첫 카드 일부만 보인다.** 여행명, 2단 탭, 가져오기/내보내기, 하단 CTA가 목록 높이를 차지한다. 펼치면 5개가 보인다. | 일정 진입 때 내용에 맞춰 확장하거나 도구를 더보기로 옮긴다. 첫 화면에서 최소 2~3곳을 볼 수 있게 한다. |
| M03 / 높음 | **패널을 펼쳐도 장소명이 짧게 잘린다.** ‘흥부왕족…’, ‘풍경닭갈…’, ‘금빛스테…’. 별점이 붙은 ‘드름산’도 ‘드름/산’ 두 줄로 나뉜다. | 카테고리를 행 위 제목으로 옮기고 장소명 영역을 넓힌다. 번호·깃발·택시·삭제를 줄이거나 보조 메뉴로 옮기며, 별점은 별도 줄에 둔다. |
| M04 / 중간 | **펼치는 방법을 알아야 정상 사용이 가능하지만 핸들 안내가 없다.** 현재 버튼 높이는 18px이고 텍스트/aria-label이 없다. | ‘목록 펼치기/접기’ 접근성 이름과 aria-expanded를 넣고 터치 영역을 확대한다. 펼치기 힌트를 제공한다. |
| M05 / 중간 | **표가 좁은 화면에 4열 그대로 들어간다.** `Day 1 · 1일차`를 매 행 반복하며 줄바꿈하고 `춘천시 (신동면)`도 갈라진다. | 모바일에는 일차별 카드/타임라인을 기본으로 사용하거나 일차를 그룹 제목으로 뺀다. Day/Time/Place/District와 min 표기도 한국어로 맞춘다. |
| M06 / 중간 | **협업자 초대 입력창이 좁다.** 이메일·권한·초대를 한 줄에 배치했다. | 이메일 입력을 한 줄 전체로, 권한과 초대를 그 아래에 배치한다. 실제 모바일 키보드가 뜬 상태에서 버튼 가림도 후속 확인한다. |
| M07 / 높음 | **‘요금제 보기’에 가격·결제 주기가 없다.** 기능 목록과 ‘Plus 업그레이드’만 표시된다. | 업그레이드 전 가격, 결제 주기, 다음 단계가 무엇인지 제공한다. 이번 점검에서는 실제 결제 버튼을 누르지 않았다. |
| M08 / 중간 | **여행 선택 메뉴에서 동일 이름을 구분하기 어렵다.** ‘태안 꽃지 하루(1일)’가 두 개 표시된다. | 마지막 수정일·대표 장소·핀 수를 함께 표시하고 현재 선택 여행을 명확히 표시한다. |
| M09 / 낮음 | **협업 활동에서 동일 문구가 반복된다.** 같은 분에 ‘나 · 여행 이름 변경’이 5건 연속 표시된다. | 변경 전후 이름을 보여주고 연속 편집을 묶어 읽기 쉽게 한다. 중복 저장 버그인지 개별 정상 수정인지 원인은 확인하지 않았다. |

## 우선 수정 순서와 검증 기준

1. M01: 390×844 반높이 상태에서 15개 검색 결과를 받았을 때 첫 장소 카드가 보이는지 확인한다. 스크롤로 마지막 결과에 도달할 수 있어야 한다.
2. M02·M03: 핀 5개인 여행에서 장소 이름을 구분하고 목록을 탐색할 수 있게 한다. ‘드름산’ 같은 짧은 이름은 부자연스럽게 꺾이지 않아야 한다.
3. M04: 패널 펼치기 동작이 보조기술에 이름과 상태를 제공하도록 한다.
4. M05~M09: 표·협업·요금제·여행 선택의 정보 표시를 정리한다.

## 확인된 정상 동작

- 반높이 → 펼침 전환 후 검색 카드가 표시된다.
- 공유 대화상자, 협업자 사람/활동 탭, 계정과 요금제 안내가 열린다.
- 기존 5곳이 표에 표시된다. 동선 설정에 이동/체류 예상이 표시된다. 실제 동선 생성 완료까지는 검사하지 않았다.
- 택시 카드에서 장소명·주소·기사에게 보여줄 문구가 읽기 좋은 큰 글자로 표시된다.

## 범위와 상태

관리자 메뉴는 이 계정의 모바일 메뉴에서 확인되지 않았다. 실제 초대 발송·공유 게시·결제·삭제·파일 업로드·동선 저장은 실행하지 않았다. 실제 iPhone 키보드, Safari, VoiceOver, 터치 드래그는 후속 검사 대상이다. 검색어와 지도 위치 등 보기 상태는 검사 과정에서 변경됐다. 마무리는 기존 여행의 펼친 일정 목록으로 두었다. 앱 소스는 수정하지 않았다.
