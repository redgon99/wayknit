# 모바일 검토 화면 증거

2026-09-13 · Chrome 390 × 844 CSS px. 실제 iPhone Safari 캡처가 아니다.

화면은 발견 당시 기록이다. 마감 시점 별도 커밋 `30bce9c`에서 U03/U15/U17 및 U08 일부가 수정됐다. 수정 후 브라우저 화면을 다시 촬영한 증거는 아니며, 수정 상태는 리포트 5절에 구분했다.

이미지는 Windows 화면 배율을 포함한다. 화면의 주황색 테두리 일부는 자동화 과정에서 표시된 키보드 포커스다. 캡처 직후 접근성 트리는 같은 이름의 JSON에 기록했다. 모달 뒤 요소가 트리에 있다는 사실만으로 손가락 터치가 배경에 통과한다고 판정하지 않는다.
