# Wayknit 홍보 영상 시나리오 (2026-10-03)

랜딩페이지 "핵심 3단계" 카피(검색&담기 → 길 엮기 → 공유&템플릿,
`src/locales/ko/landing.json`)를 축으로 짠 촬영 시나리오. 코드 작업
없이 직접 촬영할 때 쓰는 참고 문서 — HANDOFF.md §44 참고.

## 포맷

- **16:9, 60초.** `/admin/landing`의 "동영상" CMS 블록이 16:9 고정
  프레임(`landing-promo-video-frame`)이라 그대로 맞춤.
- 내레이션 없이 **자막 + 배경음악**으로만 구성 — 언어별 더빙 없이
  자막 파일만 갈아끼우면 돼서 다국어 운영에 유리.

## 촬영 장비: PC 권장

데스크톱 화면 녹화를 추천한다 — CMS 영상 블록이 16:9라 그대로 꽉
차게 들어가고, 드래그로 핀 순서 바꾸기·동선 생성 같은 세밀한 클릭
동작도 커서로 깔끔하게 보여줄 수 있어서 ④번(핵심 컷)이 또렷하게
나온다. 폰 화면은 세로(9:16)라 16:9에 넣으면 레터박스가 생기고,
손가락 터치가 화면 일부를 가려 디테일이 묻히기 쉽다.

다만 15초 쇼츠 컷(릴스/틱톡)은 반대로 폰으로 세로 녹화하는 게
맞다 — 세로가 기본 포맷이고, 짧은 구간만 보여주는 거라 디테일
부담도 적다.

## 준비물

- 알림 꺼진 깨끗한 화면, 북마크바 숨김
- 데모 장소는 랜딩 목업과 통일: 경복궁 / 인사동 카페 / 광장시장
- 화면 녹화 1920×1080 이상, 클릭 시 살짝 확대/강조되는 커서 효과
  (QuickTime·OBS 기본 기능으로 충분)
- BGM은 잔잔하다가 ④번 구간에서 한 번 고조되는 트랙 — 동선이
  그려지는 순간과 비트를 맞추면 효과적
