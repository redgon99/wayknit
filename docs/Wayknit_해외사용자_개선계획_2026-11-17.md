# Wayknit 해외 사용자 개선계획 (2026-11-17)

> **진행 상황(2026-11-17):** 0단계·1단계·2-1~2-3·3-1·4-1 완료, 자체 점검 통과. 남은 것은 HANDOFF §53 "남은 사용자 결정".

근거: 해외 사용자 관점 평가(https://claude.ai/artifact/RszenzhhGN1CRhTKvND3eJ), 최근 30일 외부 방문 기록,
현재 코드. 진행은 단계별로 하고, 각 단계가 끝나면 확인 방법을 적고 사용자 확인을 받은 뒤 다음으로 넘어간다.

## 목표

**가이드를 읽으러 온 외국인이 일정을 만들게 한다.** 지금 Wayknit은 플래너로 만들었지만 실제로는 가이드 읽을거리
사이트로 쓰인다. 새 기능보다 이 연결을 먼저 고친다.

### 출발점 (최근 30일, 내부 접속 제외)

| 지표 | 지금 |
|---|---|
| 외부 방문자 | 150명 (한국어 외 화면 74%) |
| 가이드 방문자 → 플래너 이동 | 110명 중 3명 (2.7%) |
| 플래너 방문자 | 8명 |
| 로그인 방문자 | 0명 |
| 공개 가이드 영어 번역 | 96개 중 60개. 코스 가이드는 49개 중 22개 |
| 공유마당 공개 여행 | 2개 |

### 잴 방법

- `guide_cta_click`, `guide_trip_import` 이벤트가 **2026-11-17부터** 쌓인다(§52). 그 전 기간에는 가이드 버튼
  클릭 수를 알 수 없다. 30일 동안 1건이었던 것은 버튼이 안 눌려서가 아니라 기록을 막 시작했기 때문이다.
- 접속 로그 5단계(전환 흐름 화면)를 이 계획의 측정판으로 쓴다: 가이드 조회 → 버튼 클릭 → 코스 가져오기 → 저장 → 로그인.
- 잠정 목표: 4주 안에 가이드 방문자의 플래너 이동 10%. 2주 치 기록을 본 뒤 다시 정한다.

## 1단계 — 가이드에서 일정으로 (1주, 가장 먼저)

코스 가이드 49개 중 42개에 코스 핀이 있고, 플래너는 `?autoRoute=1&fromGuide=<slug>`로 핀을 가져오는 기능이 이미
있다(`PlannerPage.tsx:596`). 문제는 버튼이 **본문 맨 아래**에 있고, 코스가 아닌 가이드에는 가져올 장소가 없다는 것이다.

| # | 할 일 | 파일 |
|---|---|---|
| 1-1 | 코스 가이드의 "이 코스로 일정 만들기" 버튼을 제목 아래로 올리고, 모바일에서는 화면 아래에 고정한다 | `GuideDetailPage.tsx`, `guides.css` |
| 1-2 | 버튼 문구를 하는 일이 보이게 바꾼다. 예: "Add this course to my trip (5 places)" | 9개 언어 `guides.json` |
| 1-3 | 코스 지도(`GuideCourseMap`)에 같은 버튼을 하나 더 둔다. 지도를 본 사람이 바로 가져가게 | `GuideCourseMap.tsx` |
| 1-4 | 코스를 가져온 직후 플래너에 짧은 안내를 띄운다. "가입 없이 이 기기에 저장됨 · 순서를 바꾸거나 날짜를 나눌 수 있음" | `PlannerPage.tsx`, `planner.json` |
| 1-5 | **조사 후 결정:** 코스가 아닌 가이드(실용·음식·쇼핑) 본문의 장소 링크에 "내 일정에 담기"를 붙일 수 있는지 본다. 본문 장소 링크는 11-05에 생겼고(`2173580`), 좌표가 있는지가 관건이다 | 조사만 |

확인 방법: 영어로 코스 가이드를 열어 버튼 위치를 보고, 눌러서 핀이 담긴 플래너가 열리는지 본다. 2주 뒤 전환

## 5단계 — 빈 화면 채우기 (지속)

- 공유마당 영어 샘플 코스: 영어 번역이 있는 코스 가이드에서 골라 운영자 계정으로 올린다.
- K-컬처 테마("Coming soon")에 최소한의 코스를 넣는다.
- 구간별 네이버·카카오 길찾기 링크는 이미 있다(`mapLinks.ts`, `RouteSummary`). 모바일에서 잘 보이는지만 확인한다.

## 하지 않을 것

- 배너 광고: 방문이 적어 수익이 거의 없고 신뢰를 깎는다.
- 월 구독 판촉: 외국인 여행은 짧아서 맞지 않는다. 4-5에서 다시 본다.
- 새 큰 기능: 1단계 전환이 오르기 전까지는 미룬다.

## 순서 요약

1. 0단계 결정 3개(시행일·슬로건·배너)를 사용자에게 받는다.
2. 0-2·0-3과 1단계를 진행한다. 2-1(응급 가이드)은 같이 한다.
3. 2단계 번역과 3-1을 진행한다. 3-2는 사용자 비용 결정을 기다린다.
4. 4-1을 하고, 사용자의 제휴 가입(4-2)이 끝나면 4-3을 한다.
5. 2주 뒤 전환 흐름 화면으로 목표를 다시 정한다.
