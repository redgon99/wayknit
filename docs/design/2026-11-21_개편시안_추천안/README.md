# Wayknit 개편 시안 · 추천안 (2026-11-21)

- 캔버스(비공개): https://claude.ai/artifact/X5jnDF8LV824JgEP7TQcfg
- 근거: `docs/Wayknit_랜딩개편_검토결과_2026-11-20.md`, HANDOFF §56·§58
- 방향: A안 구조 + B안 첫 화면(시작점 3개) + 모바일 하단 탭. 지연 로그인 유지, 수익화는 뒤로.

## 화면

| 파일 | 단계 | 내용 |
|---|---|---|
| `Main.dc.html` | 1 · 가이드 상세 (데스크톱) | 공통 헤더, 코스 지도, 장소별 "+ 담기", 오른쪽 고정 "내 일정에 담기(N곳)" 카드, 준비 체크리스트·제휴 자리, 이어서 볼 코스 |
| `GuideMobile.dc.html` | 1 · 가이드 상세 (모바일, 영어) | 하단 탭 위 고정 담기 바 |
| `MenuDesktop.dc.html` | 2 · 메뉴 3개 (데스크톱) | 코스 · 여행 정보 · 내 여행 펼침 메뉴 |
| `CoursesMobile.dc.html` | 2 · 코스 탭 (모바일, 영어) | 추천 코스 · 공유 일정 · 테마 전환, 지역 칩 |
| `LandingDesktop.dc.html` | 3 · 랜딩 (데스크톱) | 시작점 3개 + 추천 코스 카드 + 여행 정보 타일 |
| `LandingMobile.dc.html` | 3 · 랜딩 (모바일, 영어) | 시작점 3개 + 하단 탭 |

`.dc.html`은 Claude Design 캔버스 형식이라 브라우저에서 바로 열면 그려지지 않는다(`support.js`는 캔버스가 제공). 화면은 위 캔버스 링크에서 본다.

## 시안의 한계

- 사진은 색 상자, 지도는 그림이다.
- 코스 제목은 실제 공개 가이드. 영어 제목은 경주만 실제이고 나머지는 번역. "제주 3일"(이어서 하기)과 테마 칩은 예시.
